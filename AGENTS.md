# Workspace Rules & Instructions

- **Mandatory Git Auto-Commit & Auto-Push**: Whenever code changes, bug fixes, or enhancements are made and verified, automatically stage and commit the changes to Git with a concise, descriptive message (`git commit`), and immediately push to remote (`git push origin main`). Do not leave uncommitted or unpushed changes, ensuring every update automatically triggers deployment to the live Render environment (https://hospital-management-system-fbmw.onrender.com/).
