# Mandatory Git Auto-Commit Rule

After completing any code changes, bug fixes, or enhancements and verifying that the build and tests pass, always perform a Git commit automatically.

## Requirements:
1. Stage all relevant modified, created, or deleted files (`git add -A`).
2. Provide a clear, descriptive, professional commit message following Conventional Commits format (e.g., `feat:`, `fix:`, `refactor:`, `sec:`).
3. Do not leave uncommitted changes at the end of a task or turn once verification is complete.
