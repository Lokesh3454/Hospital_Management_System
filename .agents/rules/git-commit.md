# Mandatory Git Auto-Commit & Auto-Push Rule

After completing any code changes, bug fixes, or enhancements and verifying that the build and tests pass, always perform a Git commit and push automatically.

## Requirements:
1. Stage all relevant modified, created, or deleted files (`git add -A`).
2. Provide a clear, descriptive, professional commit message following Conventional Commits format (e.g., `feat:`, `fix:`, `refactor:`, `sec:`).
3. Push commits immediately to GitHub (`git push origin main`) to ensure Render auto-deployment triggers and https://hospital-management-system-fbmw.onrender.com/ stays continuously updated.
4. Do not leave uncommitted or unpushed changes at the end of a task or turn once verification is complete.
